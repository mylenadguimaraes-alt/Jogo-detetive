# Detective Quest

## Sobre o Projeto

Detective Quest é um jogo investigativo desenvolvido em linguagem C que simula a exploração de uma mansão em busca de pistas para solucionar um mistério.

Durante a investigação, o jogador percorre diferentes salas da mansão, coleta pistas, associa evidências a suspeitos e utiliza as informações obtidas para identificar o principal suspeito do caso.

O projeto foi desenvolvido com foco na aplicação prática de estruturas de dados como árvores binárias de busca, tabelas hash e listas encadeadas, além de conceitos de programação estruturada.

## Funcionalidades

- Exploração interativa de uma mansão.
- Navegação entre salas utilizando uma árvore binária.
- Coleta automática de pistas durante a exploração.
- Armazenamento de pistas em uma Árvore Binária de Busca (BST).
- Organização das pistas em ordem alfabética.
- Associação de pistas a suspeitos utilizando Tabela Hash.
- Controle de múltiplos suspeitos e evidências.
- Identificação automática do suspeito mais provável.

## Como Executar

### Utilizando o Executável

1. Baixe o arquivo `Detective_Quest.exe`.
2. Execute o programa.
3. Utilize o terminal para explorar a mansão e coletar pistas.

### Compilando o Código-Fonte


gcc Detective_Quest.c -o Detective_Quest


Para executar:


./Detective_Quest


No Windows:


Detective_Quest.exe
